# 무료 사주 맛보기 규칙 (사장님 확정 2026-10-25)

사이트 첫 화면 배너 → `#/taster`. 고객이 출생 정보를 넣으면 화면에 바로 결과가 뜬다. AI 호출 없음(0원).

## 화면 순서 (바꾸지 않는다)
1. 사주팔자 네 기둥(한자 + 한글 읽기, 태어난 해·달·날·시, "나" 표시)
2. "사주 한눈에 보기": 숫자 하나(가장 센 기운 28% 등) + 그래서 생활에서 어떤지 쉬운 말과 실제 말투로.
   용어 나열·학술 설명 금지(사장님 2026-10-25: 전문성은 용어가 아니라 풀어내는 능력으로 보여 준다). 다섯 기운 막대.
4. 좋은 운 TOP 3 → 링크 "나의 {상품} 자세히 알아보기" (초록색)
5. 조심할 운 TOP 3 → 링크 "나의 {상품} 자세히 알아보기" (빨간색)
6. 맨 아래 평생사주 칸(평생사주 그림 배경)

## 글 쓰는 방식 (모든 운 글에 지킨다)
- 근거(사주 용어 + 쉬운 뜻) → 그 사람의 생활 장면 → 끝은 "언제·어떻게는 따로 있다"처럼 결제 리포트로 이어지게.
- 좋은 운은 진짜 좋아 보이게, 조심할 운은 진짜 조심해야 할 것처럼 무게 있게. 그래도 사주 근거에 없는 말(예: "십 년에 한 번")은 쓰지 않는다.
- 쉬운 말, 비유 없는 직접 문장, 참고용·재미로 같은 말 금지.

## 결제 리포트와 내용 맞추기
- 화면 계산: `site/public/assets/free/engine.mjs`, `taster.mjs`, 글: `texts.json`
- 같은 규칙의 파이썬판: `saju/taster.py`. 주문 처리(`saju/order`)가 리포트를 쓸 때 고객이 본 좋은 운·조심할 운을
  글쓰기 재료("무료 맛보기에서 고객이 본 내용")로 넘긴다. 맛보기와 리포트는 같은 사주 계산에서 나오고, 리포트는 고객이 맛보기에서 보고 더 궁금해한 내용(특히 그 상품과 이어진 항목)을 시기·방법까지 더 깊게 푼다. 맛보기와 반대 해석은 쓰지 않는다. 8종 모두 적용(평생사주 포함, 사장님 2026-10-25). 평생사주는 6개를 알맞은 장마다 다시 꺼내 더 자세히 풀고 강조한다.
- 규칙이나 글을 바꾸면 `taster.mjs`와 `saju/taster.py`를 함께 바꾸고 `python site/tools/make_taster_fixture.py` 후
  `cd site && npm test` 로 화면과 파이썬이 400건 모두 같은지 확인한다.
- 화면 코드 `site/tools/taster_page.js`, 사이트에 넣는 곳 `site/tools/build_site.py`의 `add_taster()`.
