# 운명서재 분야별 사주 프로그램 계획

기준 파일: `/mnt/project-files/unmyeong-preview-v32.html` (운명서재 미리보기 v32)

## 0. 미리보기 검토 결과 요약

- 이 파일은 **화면(프론트엔드) 미리보기**입니다. 사주 계산, 해석, PDF 생성, 메일 발송은 들어 있지 않고 모든 결과는 예시 문구입니다. 그래서 만들 것은 이 화면이 호출하는 **분석 서버(사주 엔진 + 리포트 생성 + 주문·결제·발송)** 입니다.
- 화면에는 이미 음력 변환표(1000~2050년), 국내 시·군·구 출생지 목록(행정안전부 2026-10-10 기준), 출생 시간 정확도(정확/대략/모름) 입력, 토스페이먼츠 v2 결제 호출 코드가 준비되어 있습니다.
- 안내자 캐릭터는 모든 상품 공통 **금월선녀**, 브랜드는 **운명서재 · 나의 이야기를 펼치다**.

## 1. 공통 입력 (모든 상품)

| 항목 | 내용 |
|---|---|
| 이름 | 30자 이내 |
| 성별 | 남/여 (대운 방향 계산) |
| 생년월일 | 1940~2026년, 양력 / 음력(평달·윤달) / 양음력 미확인 |
| 출생 시간 | 정확한 시각 · 대략 범위(시작~끝, 다음 날 넘김 가능) · 모름 |
| 출생지 | 대한민국 시·도 → 시·군·구, 또는 모름 (해외 출생은 현재 접수 불가) |
| 이메일 | 결과 발송용 (결제 단계에서 입력) |

화면 코드가 서버에 요구하는 원칙: **모르는 시간·지역을 임의로 채우지 않는다** (정오, 중간값, 서울로 가정 금지). 시간이 불확실하면 가능한 모든 시주 후보를 계산해 "공통 풀이"와 "달라지는 풀이"를 나눠 보여줘야 합니다.

## 2. 공통 사주 엔진 (모든 상품이 공유)

1. 만세력: 양력↔음력(윤달), 24절기 절입 시각
2. 한국 표준시 이력 보정: 1954~1961년 UTC+8:30, 1948~1960년대·1987~1988년 서머타임
3. 출생지 경도에 따른 진태양시 보정 (시·군·구 좌표표 필요)
4. 사주팔자(년·월·일·시주), 지장간
5. 오행 분포, 십신, 12운성, 신강·신약, 격국, 용신(후보)
6. 합·충·형·파·해, 주요 신살(도화, 역마, 화개, 천을귀인 등)
7. 대운(10개), 세운(연도별), 월운
8. **불확실성 비교**: 시간 범위·지역 후보별로 결과를 모두 계산해 공통점과 차이를 표시
9. **두 사람 비교 모듈**: 일간 관계, 일지 합충, 오행 보완, 배우자궁 (재회·깊은 궁합용)

## 4. 무료·부가 콘텐츠 (유입용)

- **무료 사주** (내 안의 또 다른 나): 사주팔자, 오행 분포, 격국·신살 안내, 운명지도, 나이별 인생 등급(10~90세 슬라이더), 전생 이야기. MBTI·혈액형·사상체질 선택 입력.
- **태어난 시간 찾기**: 14개 성향 질문 → 12개 시주 후보 비율.
- **월간 운세**: 일간(갑~계) 10종 × 매달 편지형 운세.
- **인연 우주**: 친구 최대 4명 관계 보기 (카카오 로그인·초대 연결 예정).
- 프리미엄 1:1 상담 (안내 영역만 있음)

## 5. 서버가 맞춰야 할 화면 연동 규격 (코드에서 확인)

- `POST /api/intake/assess`: 입력 검증 + 분석 가능 범위 판정 (정책 버전 `kr-c-2026-10-10.2`, 계산 충돌 여부, 불확실 후보 전체 비교 여부, 고지 문구, 계산·범위 버전)
- `GET /api/payment-config`: 토스페이먼츠 클라이언트 키, 상품명
- `POST /api/orders` (Idempotency-Key) → 주문번호, 접근 토큰, 금액
- `GET /api/orders/{id}`, `/pdf` (PDF 다운로드), `/resend` (메일 재발송)
- 주문 상태: 결제 대기 → 접수 → 작성·검사 중 → (재시도/보류) → 메일 전달 완료, 취소·환불·만료·개인정보 파기
- 결제 완료 후 돌아오는 `order-status.html` 페이지는 아직 없음

## 6. 확인이 필요한 부분

1. **재물운·직업운** 리포트 목차가 화면에 없습니다 (판매 화면도 생략되어 바로 결제로 감). 목차 초안을 제가 만들어도 될지.
2. 결과 전달 방식: FAQ는 "이메일로 결과 링크", 주문 상태는 "결과 PDF 메일 전달". → **PDF 첨부 + 온라인 열람 링크 둘 다** 를 기본으로 계획.
3. 정식 오픈 전 정리할 것: 사업자 정보·약관·개인정보처리방침이 비어 있음, 후기는 예시 문구(실제 운영 시 사용 불가), 정가 대비 할인 표시는 실제 판매 이력 근거 필요.

## 7. 제작 순서 (추천)

1. **공통 사주 엔진** + 검증 테스트 (만세력 사이트 결과 대조, 시간 불확실 비교 포함)
2. **평생사주** 리포트 (가장 비싸고 엔진 기능을 대부분 사용 → 나머지 상품의 기반)
3. 두 사람 비교 모듈 → **깊은 궁합, 재회사주**, 그다음 **연애사주**
4. **재물운, 직업·이직운, 사업운** (목차 확정 후)
5. **건강운**
6. 무료 사주, 월간 운세, 태어난 시간 찾기
7. 주문·결제(토스) 서버, PDF, 메일 발송 연결 → 배포
